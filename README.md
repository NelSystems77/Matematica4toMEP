# Mate Kart 4.º – Práctica MEP

Práctica interactiva de Matemática (4.º grado, II semestre 2026, segunda prueba) con estética de carreras de karts.
Un solo archivo `index.html`, sin dependencias de compilación; compatible con GitHub Pages.

Temas: sucesiones y patrones · estadística · fracciones · números decimales · cuadriláteros.
Cada copa tiene un resumen (Pit stop) y 3 carreras progresivas (conocimiento, aplicación, resolución de problemas), más un Gran Premio final.
La pantalla "Auditoría de cobertura" verifica que cada aprendizaje esperado e indicador del temario tenga preguntas.
